# SignBridge

تطبيق للتعرّف على مجموعة من أوضاع اليد باستخدام الكاميرا، مع عرض تسميات عربية مبسّطة.

## إصدارات التطبيق

- **Windows:** يمكن تشغيل التطبيق من المصدر، أو تنزيل مثبّت Windows من قسم **Releases** بعد اكتمال بناء الإصدار عبر GitHub Actions.
- **Android:** واجهة موبايل مستقلة موجودة داخل مجلد `mobile/`. يمكن تشغيلها كصفحة ويب محلية أو استضافتها على HTTPS. تجهيز APK يتطلب بناء Android والتحقق منه على جهاز حقيقي؛ لا تعتبر نسخة Android جاهزة للتوزيع قبل نشر ملف APK واختباره.

## تشغيل نسخة Windows من المصدر

المتطلبات: Windows 10/11، Python 3.11، وكاميرا.

1. نزّل المستودع من **Code → Download ZIP** وفك الضغط.
2. شغّل `run_app.bat`.
3. بعد تثبيت المتطلبات، اضغط **تشغيل الكاميرا** داخل التطبيق.

## بناء مثبّت Windows

ملف سير العمل `.github/workflows/build-windows.yml` يبني التطبيق على Windows، ويجهّز ملف تثبيت `SignBridge-Setup.exe` باستخدام PyInstaller وInno Setup. شغّل سير العمل من تبويب **Actions**، ثم نزّل artifact الناتج بعد نجاحه.

## تطوير نسخة الموبايل

ملفات الواجهة المحمولة في `mobile/`. شغّلها عبر خادم HTTPS محلي أو استضفها على HTTPS للسماح باستخدام الكاميرا في المتصفح. الوصول إلى الكاميرا يحتاج موافقة المستخدم.

## حدود التعرّف والخصوصية

يعالج تطبيق Windows إطارات الكاميرا محليًا ولا يرفعها إلى خادم. تُطابق النسخة الحالية أوضاعًا هندسية بسيطة للأصابع، وقد تخطئ بسبب زاوية اليد أو الإضاءة أو اختلاف الحركة. هذه التسميات **ليست ترجمة معتمدة للغة الإشارة المصرية** ولا تدعم فهم الجمل أو تعبيرات الوجه أو الحركة الزمنية الكاملة. يلزم جمع بيانات مناسبة واختبار النموذج مع مستخدمين مؤهلين قبل تقديمه كأداة ترجمة.

## الملفات الأساسية

- `simple_signs_app.py` — تطبيق Windows والتعرّف على أوضاع اليد.
- `requirements-demo.txt` — مكتبات Python المطلوبة.
- `run_app.bat` — تشغيل التطبيق من المصدر.
- `installer/SignBridge.iss` — إعداد مثبّت Windows.
- `mobile/` — واجهة نسخة الموبايل.
