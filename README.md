# SignBridge — Simple Demo

نسخة مبسطة للعرض بالكاميرا، تركّز على 5 أوضاع يد شائعة بدل تشغيل مسار النموذج البحثي الكبير.

## التشغيل على Windows

**المتطلبات:** Windows 10/11، Python 3.11 من python.org مع تفعيل Python Launcher، كاميرا ويب، واتصال إنترنت لتثبيت المكتبات أول مرة.

1. اضغط **Code → Download ZIP** من المستودع وفك الضغط.
2. افتح المجلد المستخرج.
3. شغّل `run_app.bat` بالنقر المزدوج.
4. انتظر إنشاء البيئة الافتراضية وتثبيت المكتبات.
5. في النافذة اضغط **تشغيل الكاميرا** واسمح بالوصول للكاميرا.

لا تغلق نافذة الأوامر أثناء تثبيت المكتبات أو تشغيل البرنامج. سيُعاد استخدام مجلد `.venv` في التشغيل التالي.

## الحركات المعروضة

- 👍 **تمام / ممتاز** — وضع الإبهام المرفوع.
- ✋ **أهلاً / تحية** — كف مفتوح؛ تحية بصرية تقريبية وليست ترجمة مؤكدة لعبارة «السلام عليكم».
- ✌️ **سلام / إشارة النصر** — السبابة والوسطى مرفوعتان.
- ✊ **قبضة اليد** — الأصابع مطوية.
- ☝️ **السبابة** — السبابة مرفوعة.

التعرّف هنا قائم على قواعد هندسية بسيطة لنقاط اليد، وليس نموذجًا تعلّم هذه الكلمات من فيديوهات لغة الإشارة. لذلك قد يخطئ حسب اتجاه الكف والإضاءة والكاميرا، وقد تتشابه بعض الحركات مع إشارات مختلفة. لا تقدّم النتائج باعتبارها مترجمًا معتمدًا للغة الإشارة المصرية. عبارة «السلام عليكم» في لغة الإشارة قد تتضمن حركة متتابعة وسياقًا، ولا يمكن إثباتها من كف ثابت فقط.

## الملفات الأساسية

- `simple_signs_app.py` — واجهة الكاميرا والتعرّف على أوضاع اليد.
- `requirements-demo.txt` — المكتبات المطلوبة للنسخة المبسطة.
- `run_app.bat` — يجهّز البيئة ويشغّل التطبيق.
- تم حذف ملفات التجارب والنماذج القديمة غير المستخدمة لتبسيط المستودع؛ تشغيل العرض لا يحتاج تدريب نموذج.

## استكشاف الأخطاء

- إذا قال إن Python غير موجود: ثبّت Python 3.11 وفَعّل Python Launcher.
- إذا تعذر فتح الكاميرا: أغلق Zoom/Teams وأي برنامج يستخدمها، ثم أعد التشغيل.
- إذا فشل تثبيت المكتبات: تأكد من الإنترنت وشغّل `run_app.bat` مرة أخرى.
- إذا ظهرت رسالة خطأ: احتفظ بنصها كاملًا لإصلاح السبب بدل تخمينه.

## الخصوصية

يعالج التطبيق إطارات الكاميرا محليًا على الجهاز ولا يرفعها إلى خادم. لا تسجّل أو تشارك فيديوهات أشخاص آخرين دون موافقتهم.
