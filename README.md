# SignBridge

تطبيق تعليمي للتعرّف بالكاميرا على بعض مفردات لغة الإشارة المصرية باستخدام نموذج بحثي متاح علنًا. يتضمن المشروع أيضًا وضعًا منفصلًا لتجربة أوضاع اليد.

> **مهم:** هذا إصدار عرض/بحث وليس مترجمًا كاملًا أو مضمون الدقة للغة الإشارة المصرية. النموذج الخارجي يتعرف على مفردات معزولة وقد يخطئ. درجة الثقة ليست نسبة دقة مضمونة، ولا تستخدمه كوسيلة تواصل موثوقة أو بديلًا لمترجم مختص.

## التشغيل الأسرع على Windows

**المتطلبات:** Windows 10/11، Python 3.11 من python.org مع تفعيل Python Launcher، كاميرا ويب، واتصال إنترنت لأول تشغيل.

1. نزّل ZIP من فرع العرض: [تحميل نسخة demo-ready](https://github.com/Ghost7448/SignBridge/archive/refs/heads/demo-ready.zip).
2. فك الضغط في مجلد عادي، وليس داخل ملف ZIP.
3. افتح المجلد الناتج.
4. شغّل **`run_app.bat`** بالنقر المزدوج.
5. في أول مرة، انتظر تثبيت المكتبات. ستفتح نافذة التطبيق؛ اضغط **«تشغيل النظام»** وانتظر تنزيل ملفات النموذج.
6. اسمح للتطبيق باستخدام الكاميرا إذا طلب Windows ذلك.

لا تغلق نافذة الأوامر أثناء تشغيل التطبيق. قد يستغرق الإعداد الأول وقتًا بسبب TensorFlow وملفات النموذج.

### لو ظهر خطأ

- تأكد أن Python 3.11 مثبت وأن خيار **Add Python to PATH / Python Launcher** مفعّل.
- تأكد من اتصال الإنترنت ومساحة القرص.
- لو التثبيت توقف في منتصفه، أغلق النافذة وأعد تشغيل `run_app.bat`؛ سيعيد فحص الحزم.
- أغلق Zoom أو Teams أو أي برنامج آخر يستخدم الكاميرا.
- احتفظ بنص رسالة الخطأ أو صوّره لإصلاح المشكلة بدل تخمين السبب.

## أوضاع التشغيل

- **`run_app.bat`** — الوضع الافتراضي: نموذج بحثي لمفردات لغة الإشارة المصرية (ESL).
- **`run_pose_demo.bat`** — التطبيق الأساسي للتجارب على أوضاع اليد، باستخدام `model_relative.pkl`. لا يمثل ترجمة ESL.
- **`setup.bat` ثم `run_pose_demo.bat`** — تثبيت وتشغيل وضع أوضاع اليد يدويًا.
- **`run_esl_app.bat`** — نفس وضع ESL، مباشرةً.

وضع ESL يستخدم نموذجًا من [ESL-software-ml](https://github.com/abdullahsherdy/ESL-software-ml)، ويحمّل ملفات النموذج إلى `artifacts/` عند أول تشغيل. مجموعة الفيديوهات المحلية في `datasets/raw/` لم تُستخدم تلقائيًا لتدريب هذا النموذج.

## ملفات المشروع

- `esl_app.py`: واجهة كاميرا ESL البحثية.
- `src/inference.py`: تحميل النموذج ومعالجة الفريمات.
- `artifacts/`: ملفات النموذج التي تُنزّل عند التشغيل.
- `app.py`: تجربة التعرّف على أوضاع اليد.
- `train_signbridge.py`, `extract_hand_landmarks.py`: أدوات تجارب البيانات والتدريب.
- `THIRD_PARTY_NOTICES.md`: نسب المصدر وملاحظات الترخيص.
- `datasets/README.md`: مصدر بيانات الفيديو وشروط استخدامها.

## البيانات والتقييم

وجود الفيديوهات أو استخراج نقاط اليد لا يعني أن النموذج دُرّب عليها. نتائج التدريب المحلي الحالية أولية، وقد أظهرت دقة اختبار منخفضة. لا تستبدل النموذج البحثي بها قبل اختبار مستقل مناسب. راجع مصدر البيانات والترخيص قبل إعادة التوزيع، ولا ترفع تسجيلات أشخاص إلى مستودع عام دون إذن مناسب.

## الخصوصية والتراخيص

راجع `THIRD_PARTY_NOTICES.md` و`datasets/README.md`. معالجة الفيديو تتم محليًا في هذا التطبيق، بينما تنزيل ملفات النموذج يحتاج اتصال إنترنت في أول تشغيل. تجنب تسجيل أو مشاركة فيديوهات الآخرين دون موافقتهم.
