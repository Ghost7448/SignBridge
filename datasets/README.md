# بيانات لغة الإشارة المصرية — SignBridge

## مصدر البيانات

نستخدم مجموعة **Egyptian Sign Language (ESL), Version 2** من Mendeley Data:

- صفحة التنزيل: https://data.mendeley.com/datasets/39tbt2jd7r/2
- الترخيص: Creative Commons Attribution 4.0 (CC BY 4.0)
- النسخة 2 تحتوي على ملف ZIP حجمه نحو 393 MB ويضم 550 فيديو لـ 55 فئة إشارة، حسب وصف صفحة البيانات.
- النسخة 3 أحدث، لكنها تعرض ملف CSV مجمّعًا بدل ملف الفيديو المضغوط؛ لذلك استخدمنا رابط النسخة 2 لبيانات الفيديو الخام.

## لماذا ملف البيانات مش موجود جوه GitHub؟

حجم ZIP أكبر من حد GitHub المعتاد البالغ 100 MB للملف الواحد. عشان كده بنحتفظ برابط المصدر وخطوات التجهيز هنا بدل رفع نسخة كبيرة للمستودع. لا تغيّر اسماء ملفات المصدر أو تنشر نسخة معدلة بدون الحفاظ على الإسناد والترخيص.

## خطوات التجهيز

1. افتح رابط النسخة 2 ونزّل `dataset - rebirth.zip`.
2. فك الضغط داخل مجلد `datasets/raw/` في جذر المشروع.
3. شغّل من مجلد المشروع:

   ```bat
   python inspect_esl_dataset.py
   ```

4. سيعرض السكربت عدد الفيديوهات وتوزيعها حسب المجلدات، ويحفظ فهرسًا في `datasets/esl_video_inventory.csv`.

## تنبيه مهم

إضافة الفيديوهات لا تغيّر النموذج المستخدم حاليًا تلقائيًا. تطبيق `esl_app.py` ما زال يشغّل النموذج المدرّب مسبقًا من مشروع ESL-software-ml. يلزم تجهيز البيانات وتدريب/تقييم نموذج جديد بشكل منفصل قبل استبدال نموذج التشغيل. لا تعتبر نتيجة التنبؤ صحيحة لمجرد أن النموذج أعطى درجة ثقة مرتفعة.
